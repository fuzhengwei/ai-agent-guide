# AI Agent 通识教程 · 小程序上架清单（个体工商户主体 · 最终版）

> 已确定：以**个体工商户**主体注册，支持微信支付（付费解锁/卖课）+ 流量主广告。

## 你需要准备的材料（开始前拍好照/存好）

1. 个体工商户营业执照原件照片（状态须为「存续」，无经营异常）
2. 经营者身份证正反面照片
3. 经营者本人微信（用于扫码）+ 实名手机号
4. 一个**未注册过公众号/小程序的邮箱**（作为小程序登录账号）
5. 经营者本人银行卡（微信支付结算用，个人储蓄卡即可，无需对公账户）

> 若执照经营范围不含「教育咨询/信息咨询/技术服务/互联网销售」等字样，建议先去市监局做经营范围变更，否则类目审核易被驳回。

## 操作步骤

### 第 1 步：注册小程序账号（你操作，约 10 分钟）

1. 打开 https://mp.weixin.qq.com → 右上角「立即注册」→ 选「小程序」
2. 填写邮箱 → 到邮箱点激活链接
3. 主体类型选 **「个体工商户」**
4. 主体信息登记：上传营业执照、填经营者身份信息 → 法人微信扫码验证 → 人脸核验
5. 填写小程序信息：
   - 名称：`AI Agent 通识教程`（若被占用备选：`AI Agent 教程` / `Agent 通识课`）
   - 简介可参考：26 章渐进式 AI Agent 可视化教程，覆盖 LangGraph、MCP、ReAct、RAG 等，配套面试题库与在线刷题。

### 第 2 步：微信认证（你操作，300 元/年）

1. 登录小程序后台 →「设置 → 基础设置 → 微信认证 → 认证」
2. 按指引上传执照材料、支付认证费
3. 审核约 1-3 个工作日（第三方审核公司可能来电核实，接一下电话）

> 认证通过后才能开通微信支付和教育类目，这是付费功能的前提。

### 第 3 步：把 AppID 和上传密钥发给我（你操作，5 分钟）

1. 「开发 → 开发管理 → 开发设置」：
   - 复制 **AppID** 发给我
   - 「小程序代码上传」→ 生成并下载**代码上传密钥**（private.key 文件发给我）
   - 同页「IP 白名单」：先临时关闭（或把你的出口 IP 加进去，我可以帮你查）
2. 「成员管理」：把我的微信号添加为**开发者/体验者**（我发你微信号）

> 拿到这两样我就能：写入 AppID、配置 miniprogram-ci、代你上传代码为开发版/体验版。

### 第 4 步：小程序备案（你操作，上线前必须）

1. 后台首页会显示「去备案」→ 按引导填写
2. 材料：营业执照、经营者身份证、人脸核验
3. 服务内容选择：如实选「教育/学习类内容展示」
4. 审核：微信初审 1-2 天 → 通信管理局审核 1-3 个工作日（可能短信核验，注意接听）

> 备案通过前小程序不能发布上线，建议注册完立刻启动。

### 第 5 步：设置服务类目（你操作，2 分钟）

1. 「设置 → 基础设置 → 服务类目 → 添加」
2. 选择：**教育 → 在线教育**（若显示"知识付费/在线视频课程"子类也选上）
3. 按要求上传补充材料（部分情况需《产品经营说明书》：写明主营 AI 技术教程、图文/代码形式、无直播无学科培训即可）

> ⚠️ 定位保持「教程/知识付费」，**不要**申报「题库/教辅工具」类目（部分仅对企业主体开放，易驳回）。

### 第 6 步：开通微信支付（你操作，认证通过后）

1. 「功能 → 微信支付」或 https://pay.weixin.qq.com → 申请接入
2. 选择「个体工商户」→ 填执照与经营者信息 → 绑定**经营者个人银行卡**为结算账户
3. 审核通过后在商户平台（pay.weixin.qq.com）：
   - 「账户中心 → API 安全」生成 **APIv3 密钥** 和 **商户证书**
   - 「产品中心 → AppID 账号管理」关联小程序 AppID
4. 把商户号 mch_id、APIv3 密钥发我（用于配支付后端；也可等需要收款时再配）

### 第 7 步：提审与发布（你来点，我来传）

1. 我用 miniprogram-ci 上传代码 → 后台「版本管理」出现开发版本
2. 我把版本「提交审核」（此步需你扫码确认）
3. 审核通过（一般 1-7 天）→ 你在「版本管理」点「**发布**」→ 正式上架 🎉
4. 后续迭代：网站内容更新 → 我跑构建脚本 → 重新上传 → 你提审发布

- **iOS 虚拟商品**：iOS 端小程序内购买虚拟内容（课程/解锁）受微信限制，需用「虚拟支付」能力（企业主体/个体户可用，抽成与规则以微信最新公告为准）；Android 正常走微信支付
- 名称占用：注册时若「AI Agent 通识教程」被占用，用备选名，后续可改
- 认证/备案期间保持电话畅通，第三方审核与管局都可能来电核实
